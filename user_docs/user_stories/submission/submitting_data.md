# Submitting Data

To submit data to GHGA, please contact us by completing the [Pre-Submission Inquiry](https://www.ghga.de/about-us/presubmission-enquiries), which collects general information about the planned submission, or by reaching out directly via the <general:GHGA Helpdesk>. A GHGA Data Steward will be assigned to your submission and guide you through the following four steps:

  ![Flowchart with icons showing the four-step GHGA data submission process: Pre-Submission Inquiry, Data Processing Contract, Metadata Preparation, and File Upload – as described in the text below.](../../assets/img/Submission_overview_page.png){ width="800" }

1. Filing a [Pre-Submission Inquiry](https://www.ghga.de/about-us/presubmission-enquiries) or contacting us via the <general:GHGA Helpdesk>
      - A short, informal first contact: you tell us about the planned submission, and GHGA lets you know whether it can be supported and assigns a Data Steward to guide you through the rest of the process.
2. [Agreement of a Data Processing Contract with GHGA Central](dpc_preparation.md)
      - The legal step that establishes GHGA as a data processor for your institution. Covers identifying the Data Controller, reviewing and signing the contract (or, for DKFZ scientists, the Internal Terms of Use), and the information GHGA needs to prepare a sign-ready version.
3. [Preparing the Metadata for submission](submitter_guide.md)
      - How to describe your samples, experiments and datasets using the GHGA metadata model, and how that metadata is transpiled and validated before submission.
4. [Submitting the Research Data Files](RDF_submission.md)
      - How to get access to an upload box, generate the Crypt4GH keys needed to encrypt your files, and upload them using the GHGA Connector.

Signing of the Data Processing Contract has to be finalized before a Data Steward is allowed to interact with your non-personal metadata or set up an upload box for your Research Data Files. Preparing the metadata itself, however, can already start on the submitter side in parallel with the contract signing — the two steps do not have to happen strictly one after another.
